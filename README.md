# コピペ帳

iPhoneのSafari／Chromeで、長文を「始点タップ → スクロール → 終点タップ」だけでコピーし、
履歴として保存・全文選択・登録アプリへの受け渡しができるWebアプリです。
Mac・有料のApple Developer登録・App Storeは不要です。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` / `app.js` / `style.css` | Webアプリ本体（本文・履歴・設定の3タブ） |
| `bookmarklet.js` | 範囲コピーのブックマークレット本体。設定タブがこれを読み込んで登録用コードを生成する |

データ（履歴・送り先アプリ）はブラウザの localStorage に保存され、端末の外には送信されません。

## 公開手順（GitHub Pages・無料）

1. GitHubで公開（public）リポジトリ `copipe` を作り、このフォルダのファイルを置く。
2. リポジトリの Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
3. 数分後に `https://<GitHubユーザー名>.github.io/copipe/` で開けるようになる。

## iPhoneでの初期設定

1. Safariで上のURLを開き、「設定」タブの手順に従ってブックマークレットを登録する。
2. （メモアプリに送る場合）ショートカットアプリで「メモに追加」という名前のショートカットを作り、
   アクション「メモを作成」の本文に「ショートカットの入力」を指定する。

## 使い方

1. コピーしたいページでブックマークの「範囲コピー」を開く（Chromeはアドレスバーに「範囲コピー」と入力）。
2. 始点をタップ → スクロール → 終点をタップ。
3. 「コピーして保存」でクリップボードにコピーし、コピペ帳が新しいタブで開いて履歴に保存される。
4. コピペ帳の「全文選択」「全文コピー」、または「送る」のボタンで各アプリへ。

## 制約

- コピー禁止のサイト（copy イベントを打ち消しているサイト）ではコピーしません。
- SafariとChromeでは保存領域が別なので、履歴もブラウザごとに分かれます。
- Safariの「履歴とWebサイトデータを消去」で履歴も消えます。
- ホーム画面に追加したアイコンから開くと、Safariとは別の保存領域になるため、Safariのタブで使ってください。
- Instagramは本文を受け取るURLがないため、アプリが開いたあとに長押し→ペーストしてください。
